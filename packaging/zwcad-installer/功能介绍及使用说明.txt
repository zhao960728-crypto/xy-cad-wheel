小阳CAD轮盘插件（中望版）2.2.0.75｜重要说明
先选对象再用轮盘执行：支持接收预选的原生命令、别名、LISP和第三方命令直接使用已选对象；需要基点或参数时继续原有提示，不自动补回车。需要PICKFIRST=1，轮盘不会替用户修改此设置。首次加载扩展时若已有预选，加载完成后会提示重新选择并再次启动，避免初始化过程改变选择造成误操作。

一、安装
1. 必须先完整解压安装包，不能直接在压缩包内运行。
2. 右键或双击“小阳ZWCAD轮盘插件一键安装.cmd”。脚本会自动申请管理员权限。
3. 如果检测到中望CAD正在运行，安装程序会询问是否强制关闭；确认后才会关闭并继续。
4. 安装程序自动识别本机已安装的中望CAD 2020–2026 x64 版本，可同时注册多个版本，并为每个年份选择对应内核；不会向未安装版本写入无效注册项，也不会把 x64 内核注册给 32 位中望CAD。
5. 插件、配置、背景图片和日志都保存在解压后的插件文件夹；请勿在安装后移动或删除该文件夹。
6. 升级和修复安装保留用户配置，不会重置轮盘，也不会打包或写入测试命令。
7. 安装和卸载脚本兼容 Windows 7 SP1 自带的 PowerShell 2.0；Windows 7 需预先安装 .NET Framework 4.8。为避免 Win7/旧显卡把透明轮盘渲染成黑色矩形，Win7 会自动使用单层圆形兼容渲染并关闭窗口级半透明；轮盘内容、背景透明度和命令功能不受影响。

二、主要命令
XYLP：打开轮盘
XYLPSZ：设置命令和轮盘
XYLPZJ：重新自检
XYLPIME：输入法自动切换设置
XYREFRESHCMDS：手动重新读取当前中望CAD命令目录
XYRESTORELOCALCMDS：恢复中望CAD自带命令目录并清理插件命令树中的外部项
XYLPMENU：修复顶部菜单

三、快捷键和命令读取
1. 插件读取当前正在运行版本的 ZWCAD.CUIX，尽量还原中文功能名称、完整命令和组合快捷键。
2. 插件读取当前版本的 ZWCAD.pgp 命令别名；同名别名按文件中最后一条定义生效。
3. 燕秀、YX_Q 等非中望CAD核心命令统一归入“第三方命令”。“本地命令恢复”只恢复本插件命令树中的中望CAD自带命令并清理外部注入项，不删除或修改第三方 CUI/LISP/FAS/VLX/PGP，也不改用户配置。需要使用的第三方命令可使用固定Excel模板批量导入。
4. 批量导入只支持安装包提供的固定模板。TXT内容可先粘贴到新表格，按分类分列后放入固定模板。

四、执行原则
1. 轮盘只提交用户配置的命令，不修改 FILEDIA、OSMODE、ORTHOMODE 等中望CAD系统变量。
2. 命令按照当前中望CAD已经加载的命令环境执行，保留对象捕捉、动态输入、命令重定义和第三方插件环境。
3. 命令目录只在启动时读取缓存，或由用户手动刷新；点击轮盘格子时不会实时扫描CUIX。
4. 输入法自动切换只使用一个现有中文输入法：编辑已有中文或中英混合文字时首选中文，编辑纯数字/英文文字时首选英文；TEXT、DTEXT、MT、MTEXT 等新建文字命令只由“需要中文输入的命令”名单统一控制，不设置重复开关。现代输入法优先使用当前中望CAD输入线程的 TSF 状态，旧式 IMM 仅作兼容；用户选择项不可用时直接沿用 Windows 当前输入法，不任选其他项、不改写配置。普通命令结束或命令行焦点刚建立时若输入上下文尚未就绪，会进行短时有界补设，成功立即停止，不持续锁定用户手动切换。异常文本报告默认关闭，错误仍写入日志。空列表会原样保存，不自动恢复；不会持续锁定，也不切换“英语（美国）”键盘。

五、配置和日志
配置：小阳ZWCAD轮盘插件.bundle\Data\zwcad-版本.json
日志：小阳ZWCAD轮盘插件.bundle\Logs\zwcad-plugin.log
错误：小阳ZWCAD轮盘插件.bundle\Logs\errors.log
自检：小阳ZWCAD轮盘插件.bundle\Logs\self-test.json

六、当前兼容策略
本安装包兼容中望CAD标准版及机械版 2020–2026 x64，每个年份均使用对应 ZRX.NET API 独立编译，安装器会自动识别本机安装的版本类型（通过 ZWCAD 或 ZWCADM 注册表路径）并注册对应内核。当前机器已对中望CAD 2020完成启动、顶部菜单、命令读取、轮盘、自检和系统变量保持的真机验证；2021–2026 已完成对应API编译与安装器分流，仍建议在安装了相应版本的机器上运行 XYLPZJ 做最终环境验证。2019及更早版本不在本安装包支持范围内。

2.2.0.72 格子编辑更新
----------------------------------------
- 左侧每圈格数直接增减末尾格子，不弹出位置选择框。预览下方按住“＋ 加”拖到两格间的插入点松开即可加格；按住“－ 减”拖到目标格松开即可删格。删除的命令、图片和样式进入未分配命令。
- 在编辑预览中按住格子拖动到另一格交换位置，支持空格；窄窗口普通点击松开后返回编辑页。
- 图标与文字 → 显示与功能：搜索原功能名、显示名、执行命令或快捷键，选择结果绑定当前格；显示名独立保存，命令库保留原名称并标注显示名，不改执行命令。
- 图标与文字 → 文字与图片：顶部批量入口可勾选多个命令格，仅修改勾选的字体、字号、样式或颜色属性。
- 格子图片支持图标模式和背景图模式；背景图等比例铺满并按格子形状裁切。旧配置默认图标模式。
- 补充王者和小阳展开命令图标；修复经典轮盘手动字号限制、图文自动适配及设置页窄窗口布局。
- 编辑完成后点击应用并保存。图片源文件、CAD 原命令和原有配置不会被上述编辑操作直接覆盖。
- 单格显示：图标与文字 → 文字与图片 → 当前格显示，可选跟随全局、图标与文字、仅文字、仅图标。修改仅作用于选中的命令格；点击应用并保存后生效。

一键更新：设置 → 备份与维护 → 一键更新。下载、校验完成后点击退出 CAD 后安装，先保存图纸及设置并正常关闭本产品全部 CAD。等待时可取消，不会强退 CAD。安装完成后重新启动；更新目录为长期安装位置，请勿删除。更新源尚未启用时会提示清单尚未发布。
