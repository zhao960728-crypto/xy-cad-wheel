# 轮盘与输入法回归检查

最后更新：2026-09-07。适用于 `ImeAutoSwitchService`、`MouseWheelTrigger` 和 `RadialOverlayHost`。

在项目根目录执行：

```powershell
dotnet run --project tests/WheelImeRegression/WheelImeRegression.csproj -c Release
```

直接编译生产服务代码，通过测试替身提供 CAD 文档事件和输入法结果；不写入用户配置、不切换真实输入法、不发送真实鼠标点击。轮盘超时检查使用真实 WinForms STA 消息循环，覆盖排队动作过期与已开始动作迟到完成两种情况。

检查范围：成功后停止补设、普通命令失败后的六次重试上限、新焦点成功时取消旧重试、多图纸状态隔离、后台文档事件、LISP 嵌套、现有文字内容识别、CAD 退到后台、禁用输入法时的命令占用跟踪、文档关闭清理、鼠标回放边界、轮盘超时。

新增覆盖：先打开的图纸遗留命令/LISP 计数、激活事件先于当前文档更新、关闭输入法后的轮盘状态恢复，以及原生命令或 LISP 仍运行时禁止清理。

必须保持：中文命令名单、已有文字识别优先级、用户手动切换、当前 CAD 以外的软件、配置格式和原生命令执行方式。

这些检查验证服务状态和回调行为，不替代真实 CAD 中的右键操作、微信/搜狗输入法和安装升级验收。真实输入法在同一 HWND 内延迟建立编辑上下文的行为仍需在宿主中验证。

`SourceRoot` 可指向待比较的源码快照。比较旧代码时使用 `-- --ime-only` 跳过可能使旧版本进程崩溃的轮盘超时检查。
