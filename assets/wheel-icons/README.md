# 小阳 CAD 轮盘图标库

共 1,024 个图标：128 个基础图形，以及新增、编辑、复制、删除、查找、锁定、收藏七种操作变体。八类覆盖 CAD 绘制、修改、标注、文件管理、视图、建筑设施、机械工具和生活符号。

- `index.html`：离线搜索与深浅背景预览，点击图标打开原图。
- `png/`：256 × 256 透明 PNG，可在轮盘中直接选择；文件名为稳定英文标识。
- `manifest.json`：中文名称、分类、关键词和图片路径。
- `overview.png`：128 个基础图形总览。

轮盘编辑中选中已绑定命令的格子，打开“图标库 / 自选图片 / 裁剪”→“浏览内置图标库”，搜索、选择并确定。图标仍以原有 PNG 数据格式随轮盘配置备份保存。自选图标优先；恢复默认后，已知 CAD 命令使用自动匹配图标，未知命令保留文字图标。

自动匹配目录包含 212 个标准命令及常见别名的精确条目，支持常见命令宏前缀。标准别名匹配不读取或修改用户 PGP；已重定义的别名建议为轮盘绑定实际执行命令或手选图标。

图形源在 `src/XiaoYang.AutoCADPlugin/WheelIconCatalog.cs`。在项目根目录运行 `dotnet run --project tests/WheelIconRegression -c Release -- assets/wheel-icons` 可重新导出并验证。本目录是图标资产，不是插件安装包。
